# Blue Sass company seal

Original logo preserved. Use only on work actually designed or developed by Blue Sass, with the project owner's agreement. It is an authorship signature, not a certification.

## HTML
Copy seal.css and blue-sass-mark.svg to your project; include the stylesheet and paste seal.html. Adjust only the logo path and caption language. Keep the official destination link. Set data-theme to light or dark. preview.html works without a server.

## React / Next.js
Copy blue-sass-seal.tsx, blue-sass-seal.module.css, and the original SVG. Import BlueSassSeal and pass caption="تصميم وتطوير" (Arabic), "Design & development" (English), or "Ontwerp & ontwikkeling" (Dutch). Pass logoSrc if your asset path differs. No JavaScript animation, external font or dependency needed.

The component inherits text direction, supports keyboard focus, preserves minimum touch size and disables hover movement for reduced motion.
