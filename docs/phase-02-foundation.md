# المرحلة 02 — الأساس التقني وSEO

## البناء والإصدار

`npm run build` يشغّل اختبار حماية الجداول المحلي ثم Next.js فقط. لا ينفذ ترحيلات، ولا ينشئ PayPal webhook، ولا يستدعي AI Gateway. بقي فصل `.next-build` محليًا عن `.next`، واستثناء Vercel الحالي، وalias دون تعديل.

عمليات الإدارة أصبحت أوامر مستقلة:

- `npm run db:migrate`: ينفذ سكربتات الترحيل الحالية بالترتيب السابق. يتطلب نسخة احتياطية ومراجعة قاعدة الهدف وموافقة المشغّل؛ بعض السكربتات تقرأ `.env.local`/`.env`، وترحيل الاستضافة يحافظ على شرط `APPLY_HOSTING_MIGRATION=1`.
- `npm run paypal:setup`: إعداد webhook صريح، مع شروط `VERCEL_ENV=production` و`PAYPAL_ENV=live` الحالية.
- `npm run ai:verify`: فحص خارجي صريح قد يستهلك رصيد النموذج، مع شروط البيئة الحالية.

لم تُشغّل هذه الأوامر خلال التنفيذ. عند الإصدار القادم يجب نقل أي اعتماد على prebuild القديم إلى خطوة إصدار منفصلة ومراجعة. لا تنشر إصدارًا يحتاج schema جديدًا قبل تنفيذ الترحيلات المطلوبة بالطريقة المعتمدة. إعداد البناء المعتاد على Vercel يبقى `npm run build`، ولا يحتاج تغيير output directory الحالي.

## سياسة SEO

- canonical وhreflang على مستوى الصفحة، لا في layout المشترك.
- `x-default` يشير إلى اللغة الافتراضية `en` للمسار نفسه.
- صفحات `/pricing` و`/templates` المحلية تحول بالفعل إلى `/services#pricing` و`/services#templates`. بقي التحويل، وcanonical يشير إلى `/services`، والعنوانان مستبعدان من sitemap.
- تحويلات الخدمات القديمة mobile/cloud/security تحافظ على الوجهات android/erp/web ورمز 308؛ تُحسم الآن في next.config قبل التصيير لمنع تكرار Location أثناء streaming. بقيت حماية alias الحالية وdistDir دون تغيير.
- sitemap يتضمن الصفحات العامة الفعلية، والأدوات، والخدمات، ومسارات company/apps/systems؛ ويستبعد التحويلات والحسابات والنماذج الحساسة والتقارير الخاصة والمعاينات.
- لا توجد بيانات تعديل موثوقة للصفحات العامة الحالية؛ لذلك حُذف `lastModified` المصطنع. يمكن إضافته لاحقًا من سجل تعديل المحتوى الحقيقي.
- metadata الجديدة مترجمة صراحة لكل اللغات الخمس عشرة. للعربية والهولندية والإنجليزية أوصاف خاصة بكل صفحة؛ بقية اللغات تستخدم عنوان الصفحة المحلي مع وصف الاستوديو المحلي.

## الخطوط

استخدمت الملفات المحلية الموجودة للخط IBM Plex Sans Arabic، بأوزان 400 و500 و600 و700 وأجزاء Arabic/Cyrillic-ext/Latin-ext/Latin. تحقق fontkit من العائلة والأوزان. نسخت الملفات دون تغيير بايتاتها، وأبقيت unicode-range وfont-display: swap ومقاييس fallback الموجودة؛ لا preload للأجزاء كلها. Geist وJetBrains Mono دون تغيير.

المصدر المحلي: مخرجات Next.js الموجودة قبل العمل. سجل الملفات وبصماتها في `public/fonts/ibm-plex-sans-arabic/provenance.json`. ترخيص SIL OFL 1.1 ونص حقوق IBM محفوظان بجوار الملفات؛ جرى التحقق من النص الرسمي في https://raw.githubusercontent.com/google/fonts/main/ofl/ibmplexsansarabic/OFL.txt . لم تُنزّل ملفات خطوط أو تعدّلها.

## حدود التحقق

الفحص محلي. لا توجد عملية نشر أو تغيير بيانات إنتاج أو إعداد خدمات خارجية. الاختبارات لا تثبت نجاح البريد أو الدفع أو الحفظ في قاعدة الإنتاج. مراجعة الأداء والموافقة الإعلانية والعمليات الحية مرحلة منفصلة.
